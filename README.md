\# BoardGames 🎲



A 2D mobile board game developed with Unity.



\## Games



This project includes:



\- Snake \& Ladders

\- Ludo



\## Features



\- Offline local multiplayer

\- Supports 2 to 4 players

\- Landscape mobile layout

\- Turn-based gameplay

\- Dice rolling

\- Pawn movement

\- Snake and ladder mechanics

\- Ludo final paths

\- Capturing opponent pawns

\- Player ranking system

\- Replay and Main Menu

\- Sound effects

\- Background music

\- Persian RTL user interface



\## Built With



\- Unity 2022.3.62f1

\- C#

\- TextMeshPro

\- RTLTMPro



\## Project Structure



The project contains separate scenes and systems for:



\- Main Menu

\- Player Setup

\- Snake \& Ladders

\- Ludo
